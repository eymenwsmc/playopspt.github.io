Play Minecraft in your browser

Pick a version below, click PLAY, and jump right in. Singleplayer worlds save directly in your browser with no Java or desktop installation needed.

PLAY
Your Worlds & Saves

Singleplayer saves persist directly in your browser. You can export .epk world backup files from the Singleplayer menu anytime so you never lose progress.

Multiplayer Relays

Web browsers connect using WebSockets (wss://). Check the Community Servers tab to copy server addresses and paste them into in-game Direct Connect.

Performance Tips

Runs smoothly on Chromebooks, Mac, Linux, and Windows. If you experience FPS drops on low-spec laptops, set render distance to 4–6 chunks in Video Settings.

How to join a community server

Because web browsers cannot connect to raw TCP Minecraft sockets, Eaglercraft uses secure WebSockets (wss://).

  1. Click the copy button on any server above to copy its wss:// address.
  2. Launch your chosen version (e.g. 1.20.6, 1.14.4, or 1.7.10).
  3. Go to Multiplayer → Direct Connect (or Add Server).
  4. Paste the copied address and click Join Server!
