Eaglercraft 1.20.6 pre-release WASM
Initial Build

First release of Eaglercraft 1.20 compiled to modern WebAssembly. Includes community optimizations, modern block rendering, and WebSockets.

Key Highlights

  • Optimized 1.20 engine codebase for smooth in-browser execution.
  • Fixed bugs of 1.20 for client-side web compatibility.
  • TeaVM and WebAssembly runtime integration.
  • WebGL rendering pipeline and modern block/item support.
Eaglercraft 1.14.4 u1 WASM
Update 1 (u1)

Village & Pillage update compiled to WebAssembly. Smooth performance on low-spec hardware and Chromebooks.

Bug Fixes

  • Fixed water color rendering.
  • Fixed stats screen crashing the game.
  • Fixed villager interaction and boat crash bugs.
  • Fixed 15th Anniversary cape filename resolution.
  • Fixed shield banner blur and cobweb item holding.
  • Fixed bed sleep mechanics and server resource pack cleanup.
  • Fixed GUI slider controls and chunk boundary issues.
  • Fixed crystal explosion mechanics on WASM runtime.

Added Features

  • Added mobile touch control support.
  • Optimized entity culling and render allocations.
  • Integrated voice client and world HUD stats.
  • Added world import/export and server notifications.
  • Added profanity filter options and datapacks GUI.
