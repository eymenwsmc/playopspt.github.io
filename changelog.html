Version Changelog

Technical release notes, WebAssembly compilation details, and feature updates across all Eaglercraft versions.

Eaglercraft 1.20.6 pre-release WASM
First Release

First release of Eaglercraft 1.20 compiled to modern WebAssembly. Includes eagler features, optimizations, and many more.

Key Highlights

  • Optimized 1.20 engine codebase for smooth in-browser execution.
  • Fixed bugs of 1.20 for client-side web compatibility.
  • Got it to work with TeaVM and WebAssembly runtime.
  • WebGL rendering pipeline and modern block/item support.
