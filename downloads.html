How Offline HTML Files Work

These packages contain the entire game code, WebAssembly/JavaScript engine, audio, and textures compressed inside a single .html document. You can store the file on a USB flash drive or local drive and open it with Chrome, Firefox, Safari, or Edge without an internet connection.

Worlds and settings automatically persist inside your browser storage.
