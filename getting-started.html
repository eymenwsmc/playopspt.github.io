Getting Started with Eaglercraft

Everything you need to know about browser Minecraft: runtime architecture, saving singleplayer worlds, FPS tweaks, and custom skins.

1 What is Eaglercraft and How Does it Run?

Eaglercraft is an ahead-of-time (AOT) transpiled version of Minecraft created to execute inside modern web browsers. Instead of requiring a Java Runtime Environment (JRE) or desktop installer:

  • TeaVM & WebAssembly (WASM): Converts original Java bytecode directly into high-performance WebAssembly binary code or optimized JavaScript.
  • WebGL OpenGL Emulator: Maps desktop OpenGL 1.2 / 2.1 graphics calls to WebGL shaders, rendering 3D block voxels smoothly on standard graphics hardware.
  • IndexedDB Filesystem: Simulates a standard disk file structure entirely inside the browser’s sandboxed database.

2 How to Save and Backup Singleplayer Worlds

Singleplayer worlds are stored locally in your browser’s IndexedDB storage. While persistent across normal restarts, clearing browser history or site cookies will delete stored worlds.

How to create a safe backup (.epk file):
  1. Open the Singleplayer menu.
  2. Select your world and click Backup / Export.
  3. Save the resulting .epk file to your Google Drive, USB stick, or local hard drive.
  4. To restore, click Import World and choose your saved .epk backup.

3 Chromebook & Low-Spec Performance Optimization

If you are playing on a school Chromebook, Intel Celeron laptop, or older MacBook, follow these settings to double your frame rate (FPS):

  • Render Distance: Set to 4 Chunks or 6 Chunks.
  • Graphics: Switch from Fancy to Fast.
  • Smooth Lighting: Turn OFF.
  • Particles: Set to Decreased or Minimal.
  • Max Framerate: Set to 60 FPS or VSync to prevent CPU thermal throttling.

4 Uploading Custom Skins

You don't need an official Mojang account to use custom skins in Eaglercraft.

  • Go to Options → Edit Skin in the main menu.
  • Click Upload Skin and select any PNG skin image.
  • Both classic 64x32 format and modern 64x64 layers (including jackets, hats, and sleeves) are fully supported.
