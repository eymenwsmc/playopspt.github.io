How to Join a Multiplayer Server

  1. Launch any Eaglercraft build from our Catalog.
  2. Click Multiplayer from the game's title screen.
  3. Click Add Server.
  4. Enter any server name and paste the WebSocket URI into the server address field (e.g. wss://tuff.ws).
  5. Click Done, select the server, and click Join Server!

How Does Eaglercraft Networking Work?

Standard Minecraft Java servers communicate using raw TCP packets. Because web browser security sandboxes block direct TCP sockets, browser clients connect via protocol translation layers like EaglercraftXServer (a.k.a. EaglerXServer) created by lax1dude.

What is EaglercraftXServer?

EaglercraftXServer is an industrial-grade server plugin that changes how frames (and a few packets) are encoded in the Minecraft protocol to make it compatible with web browsers and extend client capabilities. It does not tamper with server authentication settings or modify inbound connection authentication states.

  • Universal Single-JAR Deployment: Installs directly on Spigot, BungeeCord, or Velocity from a single unified JAR file (requires Java 17+).
  • Cross-Platform Server API: Provides native APIs for custom player skin relays, integrated voice chat channels, cookie authentication, and a backend RPC protocol to access Bungee/Velocity APIs from backend Spigot servers.
  • Packet Translator Ecosystem: Supports extensions such as EaglerXRewind (translating packets for 1.5.2 clients like ViaVersion), EaglerMOTD, EaglerWeb, and EaglerXSupervisor for multi-proxy synchronization.
  • SSL / TLS (wss://) Security: Servers must use wss:// (WebSocket Secure) when accessed from HTTPS web portals to meet browser mixed-content security requirements.
